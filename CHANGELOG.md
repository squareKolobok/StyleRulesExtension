# Список изменений

## [1.0.4] 2026-02-08

- Удалено срабатывание на необязательные скобочки в if-else, когда в теле содержится одно выражение на несколько строк

## [1.0.3] 2025-12-09

- Убрано срабатывание для _unnecssary_if_braces_, чтобы не удалял скобочки в теле if-else, если в теле находится другой одинокий if без else. Исключает случаи возникновения неправильного поведения кода после удаления скобочек.

## [1.0.2.1] 2025-12-30

- Убрано срабатывание на неправильное имнование методов для свойств
- Изменена область обнаружения ошибок при обнаржкнии необязательных скобочек

## [1.0.2] 2025-12-29

- Добавлено Readme
- Изменено преобразование в UpperCase и CamelCase

## [1.0.1] и ранее

Использовать не рекомендуется
